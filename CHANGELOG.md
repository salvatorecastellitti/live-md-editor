# live-md-editor

## 0.1.0

### Minor Changes

- 65d7b12: First release: WYSIWYG markdown editing with GFM, task and radio lists, a React wrapper and a default theme. Stream AI answers in as they arrive (`stream`, `streamFrom`, or the React `streaming` prop), with unfinished syntax repaired while they render. Optional code highlighting (`live-md-editor/highlight`, languages load on demand) and a copy button on code blocks.
